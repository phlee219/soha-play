# 소하 놀이터

22개월 아이를 위한 한국어 낱말·동물 놀이 앱(PWA). 갤럭시탭 홈 화면에 설치해 전체화면·오프라인으로 씁니다.

- 앱 주소: https://phlee219.github.io/soha-play/

## 놀이 3가지

| 놀이 | 내용 | 배우는 것 |
|---|---|---|
| 낱말 카드 | 가족 사진 카드와 기본 낱말(사과, 공 …). 누르면 크게 뜨고 이름을 들려줌 | 이름 붙이기 |
| 동물 까꿍 | "누가 숨어 있을까?" → 문/풀숲을 열면 "소!" … "음매, 음매" | 기대하기, 소리 흉내 |
| 어디 있지? | "멍멍이 어디 있어?" → 2~4개 중 고르기. 틀리면 정답이 반짝이며 알려 줌 | 듣고 알아보기(수용 어휘) |

화면 시간을 줄이는 장치:

- **한 번에 놀 시간**(기본 10분)이 지나면 "오늘은 여기까지!" 화면. 부모가 버튼을 2초 꾹 눌러야 다시 시작. 30분 넘게 쉬면 새 세션.
- 화면 아래 **부모 도움말**: 같이 말하고, 흉내 내고, 진짜 물건을 가리켜 보라고 안내.
- 부모 설정에 **최근 7일 사용 시간** 표시.
- 번쩍이는 보상·광고·자동 재생 없음.

## 소리

- 기계 TTS를 쓰지 않습니다. 동물·기본 낱말은 Microsoft 신경망 음성(ko-KR-SunHiNeural)으로 **미리 만든 mp3**(`app/audio/`).
- 가족 카드는 부모가 직접 **녹음**(최대 5초). 녹음한 카드는 "어디 있지?"에도 나옴("엄마" + "어디 있어?").

## 부모 설정

홈 화면 오른쪽 아래 ⚙️를 **1.5초 꾹**. 놀이 화면의 🏠도 꾹 눌러야 나가집니다.

- 📷 사진 고르기 → 이름 입력 → ⏺ 이름 녹음 → 저장
- 사진·녹음은 **그 태블릿 안(브라우저 저장소)에만** 저장되고 업로드되지 않습니다. 앱을 지우거나 Chrome 사이트 데이터를 지우면 함께 지워집니다.

## 태블릿에 설치

1. 갤럭시탭 Chrome에서 앱 주소를 엽니다.
2. 메뉴(⋮) → **홈 화면에 추가 / 앱 설치**.
3. 인터넷이 될 때 한 번 실행하면 음성 파일까지 저장돼 이후 오프라인으로 됩니다.
4. 다른 앱으로 못 나가게: 설정 → 보안 → **앱 고정**을 켜고, 최근 앱 화면에서 이 앱 아이콘 → 이 앱 고정.

## 고치기

- 동물·낱말 추가/수정: `app/content.json` 수정 후 `tools\.venv\Scripts\python tools\make_audio.py` (새 문장만 생성, 전부 다시는 `--force`). 음성을 바꾸면 `app/sw.js`의 `VERSION`을 올립니다.
- 환경 준비: `py -3 -m venv tools\.venv` → `tools\.venv\Scripts\python -m pip install edge-tts`
- PC 미리 보기: `app` 폴더에서 `py -3 -m http.server 8765` → http://localhost:8765 (file://로는 안 됨)
- `main`에 push하면 GitHub Actions가 `app/`을 GitHub Pages에 배포합니다.
